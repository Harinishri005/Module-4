## CLASS AND OBJECTS - AREA OF CIRCLE

### AIM  
To write Python Program to take the radius from the user and find the area of the circle using class name 'pen' and function name 'stationary'

### ALGORITHM

1.Start

2.Define a class named pen.

3.Inside the class, define a method called stationary that:

4.Takes one parameter: radius.

5.Calculates the area using the formula: area = π * radius².

6.Returns the computed area.

7.Prompt the user to input the radius.

8.Convert the input into a floating-point number.

9.Create an object of class pen.

10.Call the stationary method using the object, passing the radius as an argument.

11.Display the result (area of the circle).

12.End

### PROGRAM

```
import math
class circle:
    def area(r):
        return math.pi*r*r
r=int(input())
obj=circle
print("Area of circle:",round(obj.area(r),2))
```
