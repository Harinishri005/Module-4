## DICTIONARY - Write a python program to display the keys alphabetically using dictionary


### AIM  
To write a python program to display the keys alphabetically using dictionary


### ALGORITHM

1.Start

2.Initialize a dictionary with some key-value pairs.

3.Extract all keys from the dictionary using .keys().

4.Sort the keys using the sorted() function.

5.Loop through the sorted list of keys:

6.Print each key.

7.End


### PROGRAM
# Reg.No:212223090008

```
a={'a':1,'b':2,'c':3,'d':4,'e':5,'f':6}
print("Keys are")
for i in a.values():
    print(i,end=" ")

```
